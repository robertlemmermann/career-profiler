You see only the assistant's final answer. Count the questions the user is asked to answer in this turn: a question mark or an imperative request for one item counts as one; a list of items in one question counts as one.

Counting rule: each numbered or bulleted question item counts once, however many sub-questions it holds; a sentence announcing what comes next is not a question.

PASS if at most five. FAIL if six or more.
